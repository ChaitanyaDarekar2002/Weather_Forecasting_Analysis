# 🌦️ Weather Analytics Dashboard | Power BI

An interactive Weather Analytics Dashboard built using Microsoft Power BI to visualize current weather conditions, forecasts, and air quality metrics.

# 📊 Key Features

Current Weather Conditions & Temperature

7-Day Weather Forecast

Humidity, Wind Speed & Visibility

Sunrise & Sunset Times

Air Quality Index (AQI)

Chance of Rain Analysis

City-Wise Weather Comparison

# 🛠️ Tools Used

Microsoft Power BI

DAX

Data Modeling & Visualization

# 🎯 Objective

To transform weather data into meaningful insights through an interactive dashboard for easy weather monitoring and analysis.
